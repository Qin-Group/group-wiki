This is a website for research-related documentation and resource for the [Qin group](https://ssqinlab.com), built with [Just the Docs]. It is meant to be a starting point for group members who first join the group. It could also be useful for anyone who want to learn more about the tools used in theoretical and computational neuroscience.

Group members are encouraged to contribute to this website by adding new pages or updating existing ones.

The reading materials and tutorials are organized into several categories:
- [Reading materials](#reading-materials): Overview of the field, classic research papers, and recommended books for different topics. Ranging from mathematics, physics, computer science, neuroscience, and machine learning.
- [Tools](#tools): programming languages, software, and databases used in the group.
