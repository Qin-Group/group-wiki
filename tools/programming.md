# Linux systems
## Linux subsystem for Windows
If you are using Windows 10 or later, you can install Windows Subsystem for Linux (WSL) to run a Linux environment directly on Windows without the overhead of a traditional virtual machine or dual-boot setup. You can follow the official Microsoft guide to install WSL:  
[Install WSL](https://learn.microsoft.com/en-us/windows/wsl/install)

## Slurm
Slurm is a highly scalable cluster management and job scheduling system for large and small Linux clusters. It is used by many of the world's supercomputers and computer clusters. 
- [Slurm official documentation](https://slurm.schedmd.com/documentation.html)
- [STJU HPC Slurm User Guide](https://docs.hpc.sjtu.edu.cn/job/slurm.html)
